qbsearch 0.1.0 is the first hardened release of the qBittorrent
search-plugin collection.

## Highlights

- Added 61 standalone nova3 search engines in `plugins/`, each installable on
  its own with no shared repository runtime.
- Added the generated stdlib-only safety preamble (bounded retries, explicit
  timeouts, bounded thread-pool parallelism, locked result printing) while
  preserving qBittorrent Python 3.9 compatibility.
- Added `catalog/plugins.json` as the metadata source of truth with generated
  plugin documentation.
- Added native collection installers and repository checks (Ruff,
  BasedPyright, installability harness, live smoke tests).

## Install the collection

1. Download `qbsearch-0.1.0.zip` below.
2. Extract the archive and quit qBittorrent.
3. Run the installer for your platform.
4. Relaunch qBittorrent and open the Search tab.

The archive contains all standalone plugin engines, matching icons, support
files, and the native installers. No Python, Bun, or repository checkout is
needed on the target machine.

For single-plugin installation, use the generated catalog documentation to
open an individual plugin source file.
