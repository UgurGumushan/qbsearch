qbsearch 0.1.1 fixes the static checks in the release environment so tagged
builds gate cleanly.

## Highlights

- Fixed the Python checker environment used by the release workflow
  (`pyproject.toml`, `requirements-dev.txt`, safety-test harness).
- No plugin engine changes; the installable collection is identical to 0.1.0.

## Install the collection

1. Download `qbsearch-0.1.1.zip` below.
2. Extract the archive and quit qBittorrent.
3. Run the installer for your platform.
4. Relaunch qBittorrent and open the Search tab.

The archive contains all standalone plugin engines, matching icons, support
files, and the native installers. No Python, Bun, or repository checkout is
needed on the target machine.
