qbsearch 0.1.7 improves plugin reliability and contributor checks and reduces
the collection to 49 engines after a live-probe maintenance pass.

## Highlights

- Bound search work and response reads, honor search deadlines during retries,
  and improve duplicate handling and parser resilience across the collection.
- Add deterministic plugin quality checks and maintenance evidence validation.
- Focus the README on installation and use, with development guidance in
  CONTRIBUTING.md.
- Preserve standalone engines and Python 3.9 compatibility.

## Removed engines and live-probe evidence

The earlier live sweep reported 49 passing probes and 12 failing probes across
61 engines. This release removes the 12 engines with failing probes:

- anidex: HTTP 502.
- calidadtorrent, kickasstorrents, and mejortorrent: HTTP 403.
- cloudtorrents, magnetdl, and redetorrent: HTTP 522.
- glotorrents: HTTP 500.
- goggames: HTTP 404.
- rockbox and yggtracker: aborted after three attempts.
- torrentgalaxy: connection failure.

These observations include access blocks and transient network failures; they
do not prove that every removed engine or site is permanently broken. Passing
probes also do not guarantee that searches return usable results. Query strings
were not retained in the available summary, so this release does not claim a
reproducible query-level validation record or a new live sweep.

The removed engines are absent from the archive. Existing installations may
retain older copies; remove unwanted engines in qBittorrent's Search plugins
dialog.

## Install the collection

1. Download qbsearch-0.1.7.zip or qbsearch-latest.zip below.
2. Extract the archive and quit qBittorrent.
3. Run install/macos.sh on macOS, install/linux.sh on Linux, or
   install/windows.ps1 in Windows PowerShell.
4. Relaunch qBittorrent and open the Search tab.

The archive includes standalone plugin engines, matching icons, support files,
and platform installers. See documentation/INSTALL.md in the archive for setup
requirements and single-plugin installation instructions.
