qbsearch 0.1.10 overlaps more independent search requests and streams results
as they finish. The collection contains all 49 standalone Python 3.9-compatible
engines, matching icons, support files, and installers for macOS, Linux, and
Windows.

## Highlights

- Replace the fixed four-worker pool with a hardware-based 4–16 worker default.
  Set `QBSEARCH_MAX_WORKERS` in qBittorrent's launch environment to choose a
  limit from 1–16.
- Stream completed work while preserving page or seed order where required.
  Bound pending jobs and response buffering, isolate worker failures, and
  prevent nested pools from multiplying active requests.
- Parallelize AudioBook Bay's unique detail lookups and known search pages.
  Fetch YTS's remaining API pages concurrently and retain later valid results
  if one page is malformed.
- Restructure Darklibria's page/detail scheduling so searches with few pages
  can still use the detail worker budget.
- Add concurrency regression checks and document measurements, configuration,
  and live-service evidence in `documentation/PERFORMANCE.md`.

## Controlled performance measurements

Five-run median measurements compare this release with 0.1.9 on a 16-core host
running Python 3.9.6. Saved responses use fixed artificial delays to isolate
request scheduling from remote-site variability.

| Workload                                  | Before |  After | Speedup |
| ----------------------------------------- | -----: | -----: | ------: |
| Shared helper: 64 independent requests    | 543 ms | 139 ms |   3.92× |
| AudioBook Bay: eight pages and 32 details | 988 ms | 125 ms |   7.89× |
| YTS: eight API pages                      | 190 ms |  53 ms |   3.58× |
| Darklibria: two pages and 32 details      | 248 ms | 103 ms |   2.40× |

Actual-engine benchmarks produced identical result dictionaries and request
counts before and after. A separate streaming workload reduced first-result
latency from 151 ms to 6.4 ms and peak traced allocations from 32.0 MiB to
14.1 MiB. Python 3.11 repeats showed similar throughput improvements. These
measurements apply to the controlled workloads; live gains depend on each
remote service, query, and available independent work.

## Validation and live-service limits

- Full strict deterministic checks passed on Python 3.9 and 3.11, with all 90
  tests passing on each interpreter, plus static and generated-file audits.
- The website production build and all 49 engine installability checks passed.
  Engine IDs, version declarations, and qBittorrent result fields are preserved.
- The initial all-49 required-markers live sweep reported 25 passes and 24
  failures. The later 47-plugin sweep outside the shared Bitsearch/Solid
  Torrents backend repeated 23 passes and the same 24 failing IDs.
- Fresh actual-parser pairs for Bitsearch and Solid Torrents each produced 40
  usable records per query. A later Solid Torrents smoke probe returned HTTP
  429, so both shared-backend checks stopped. Current-source recovery and
  separated-day promotion checks remain pending in the maintenance log.
- Fresh YTS data produced three usable results for `inception`. AudioBook Bay's
  `the hobbit` capture timed out; Darklibria's HTTP 200 response for that query
  produced no records. Generic marker probes do not execute Python parsers or
  verify torrent downloads.

Catalog totals are 44 active, three intermittent, and two unavailable. These
statuses reflect recorded evidence and do not guarantee current availability.
Performance changes do not repair unavailable or changed remote endpoints.

## Install or update the collection

1. Download `qbsearch-0.1.10.zip` or `qbsearch-latest.zip` below and extract it.
2. Quit qBittorrent completely, then open Terminal or PowerShell in the extracted
   `qbsearch-0.1.10` folder.
3. Run the command for your platform:

   | Platform             | Command                 |
   | -------------------- | ----------------------- |
   | macOS                | `sh install/macos.sh`   |
   | Linux                | `sh install/linux.sh`   |
   | Windows (PowerShell) | `.\install\windows.ps1` |

4. Reopen qBittorrent and use **Search → Search plugins** to enable the engines
   you want. The complete collection includes the Adult entries in the catalog.

The installers replace existing collection plugin files and preserve support
settings. See the included README and `documentation/INSTALL.md` for setup
instructions, and `documentation/LICENSE_PROVENANCE.md` for upstream licensing.
