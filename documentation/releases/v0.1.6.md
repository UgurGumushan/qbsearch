qbsearch 0.1.6 is a maintenance release: a live-sweep triage pass and a
cleaner, faster maintainer toolchain.

## Highlights

- Triaged the weekly live sweep: `goggames` is retired, three dead sites are
  marked `unavailable` in the catalog until they return, and `mikanani` moved
  to its new domain.
- Added offline probe-URL fixtures with drift detection, so probe targets are
  reviewed in git instead of relying on live network passes.
- Reduced the command surface to six commands: `setup`, `check`, `gen`,
  `plugin`, `test`, `release`.
- `check -- --fast` now audits generated files (catalog docs, safety
  preambles, CLI docs, probe fixtures) before every commit, matching the
  documented behavior.

## Install the collection

1. Download `qbsearch-0.1.6.zip` or `qbsearch-latest.zip` below.
2. Extract the archive and quit qBittorrent.
3. Run the installer for your platform:
   - macOS: `./install/macos.sh`
   - Linux: `./install/linux.sh`
   - Windows PowerShell: `./install/windows.ps1`
4. Relaunch qBittorrent and open the Search tab.

The archive contains all standalone plugin engines, matching icons, support
files, and the native installers. No Python, Bun, or repository checkout is
needed on the target machine.

For single-plugin installation, use the website directory or the generated
catalog documentation to open an individual plugin source file.
