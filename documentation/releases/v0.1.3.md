qbsearch 0.1.3 hardens every plugin engine for strict linting and type
checking while preserving qBittorrent Python 3.9 compatibility.

## Highlights

- Hardened all plugin engines and support tooling for strict linting and type
  checking.
- Added safer live-test adapters and runtime validation across the plugin
  collection.
- Fixed live testing for AnimeTosho feeds that omit peer counts.
- Pinned `typing_extensions` for the CI checks.

## Install the collection

1. Download `qbsearch-0.1.3.zip` below.
2. Extract the archive and quit qBittorrent.
3. Run the installer for your platform.
4. Relaunch qBittorrent and open the Search tab.

The archive contains all standalone plugin engines, matching icons, support
files, and the native installers. No Python, Bun, or repository checkout is
needed on the target machine.

For single-plugin installation, use the generated catalog documentation to
open an individual plugin source file.
