qbsearch 0.1.2 reworks the RARBG engine for the JSON search API and adds
published dates across the collection.

## Highlights

- Updated the RARBG plugin for the JSON search API.
- Added published-date extraction to a dozen engines, including AnimeTosho,
  Nyaa Pantsu, Nyaa Sukebe, DMHY, Mikan, Tokyo Toshokan, SolidTorrents,
  The Pirate Bay, EliteTorrent, and Mejortorrent-family engines.
- Added a qBittorrent Search tab screenshot to the README.

## Install the collection

1. Download `qbsearch-0.1.2.zip` below.
2. Extract the archive and quit qBittorrent.
3. Run the installer for your platform.
4. Relaunch qBittorrent and open the Search tab.

The archive contains all standalone plugin engines, matching icons, support
files, and the native installers. No Python, Bun, or repository checkout is
needed on the target machine.

For single-plugin installation, use the generated catalog documentation to
open an individual plugin source file.
