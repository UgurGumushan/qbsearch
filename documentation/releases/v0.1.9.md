qbsearch 0.1.9 makes the collection easier to download, install, and browse, and
includes deterministic test fixes made after 0.1.8. The archive contains all 49
standalone search engines, matching icons, support files, and platform installers.

## Highlights

- Put a direct latest-release ZIP download at the top of the README.
- Document collection installation and updates for macOS, Linux, and Windows,
  plus qBittorrent's individual-plugin installation steps.
- List every plugin in the README, grouped by category, with direct Python-file
  downloads and catalog statuses: 44 active, 3 intermittent, and 2 unavailable.
- Correct the Python 3.9+ prerequisite and remove a retired troubleshooting
  command from the installation guide. Shell commands work from extracted ZIPs
  without requiring executable permissions on the installer files.
- Allow functional-capture tests 30 seconds on slower CI runners while retaining
  individual replay, request, URL, and capture limits. Explicit loader typing
  also keeps the parser harness clean under Python 3.9 static checks.

Catalog statuses reflect recorded maintenance evidence and do not guarantee
current remote-site availability. See the detailed plugin catalog for site
links, known issues, and per-engine licensing information.

## Install the collection

1. Download `qbsearch-0.1.9.zip` or `qbsearch-latest.zip` below and extract it.
2. Quit qBittorrent completely, then open Terminal or PowerShell in the extracted
   `qbsearch-0.1.9` folder.
3. Run the command for your platform:

   | Platform             | Command                 |
   | -------------------- | ----------------------- |
   | macOS                | `sh install/macos.sh`   |
   | Linux                | `sh install/linux.sh`   |
   | Windows (PowerShell) | `.\install\windows.ps1` |

4. Reopen qBittorrent and use **Search → Search plugins** to enable the engines
   you want. The complete collection includes the Adult entries in the catalog.

The installers update plugin files and preserve existing support settings.
The included README and documentation/INSTALL.md provide setup instructions;
documentation/LICENSE_PROVENANCE.md records upstream license provenance.
