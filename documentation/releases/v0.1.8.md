qbsearch 0.1.8 restores search parsing, strengthens functional verification and
plugin scaffolds, and records upstream license provenance. The collection retains
all 49 standalone engines and Python 3.9 compatibility.

## Highlights

- Restore Elitetorrent's encoded magnet extraction and Solid Torrents parsing
  for the current redirected listing.
- Verify initial Bitsearch and Solid Torrents recovery with fresh Bun captures
  replayed through the actual Python engines. Both remain `intermittent` pending
  three additional clean functional checks on separated days.
- Repair Pirateiro desktop result rows, duplicate handling, global result caps,
  and escaped magnet/download-button resolution.
- Add bounded actual-engine search and download verification for Ali213,
  Pirateiro, and Traht. Python replay remains offline; Bun captures HTTP responses
  and validates resolved magnets or structurally valid torrent metadata.
- Preserve HTTP 429 and Retry-After evidence even when response bodies are
  interrupted or oversized. Add Windows-1251 decoding for captured responses.
- Improve conservative quality analysis, resolving 37 of 39 advisory warnings;
  retain two manually reviewed advisories rather than suppressing them.
- Harden JSON and HTML scaffolds with argument validation, retry/deadline helpers,
  malformed-row tolerance, deduplication, and result limits.
- Audit all 26 previously unresolved upstream license labels: verify eleven,
  document fifteen unresolved entries, and ship six exact upstream license notices.

## Current functional evidence and follow-up

Elitetorrent emitted usable magnet results for `inception` and `matrix` after
repair. Bitsearch and Solid Torrents each completed two qualifying initial
recovery passes with 40 usable results per query. Their October 2, 3, and 4
promotion checks remain manual follow-ups; this release does not claim those
future checks have passed.

Pirateiro's repaired parser emitted five valid listing records for each of
`inception` and `ubuntu`, and its required-results smoke probe passed. Detail
requests timed out, so downloadable results remain unverified and its status
stays `unavailable`.

Ali213 emitted zero records for `minecraft` and `elden ring` despite HTTP 200
search and game pages. No usable replacement for its obsolete download chain was
established. Traht's `inception` and `matrix` browse responses were empty HTTP 200
bodies. Ali213 remains `unavailable`; Traht remains `intermittent` pending follow-up.

No engines are removed in this release. Removal requires unsuccessful recovery
work followed by complete failed functional pairs on two separate Istanbul dates.
Ali213 and Traht have a completed negative pair on October 1; their earliest
second date is October 2. Pirateiro's interrupted captures earn no removal credit.
Rate limits and infrastructure failures also do not count as complete negative pairs.
See documentation/MAINTENANCE_LOG.md in the repository for the evidence and policy.

Torrent metadata validation checks structure; it does not download torrent
payloads or establish their content or cryptographic integrity. Catalog statuses
reflect recorded maintenance evidence, not a guarantee of remote site uptime.

## Install the collection

1. Download `qbsearch-0.1.8.zip` or `qbsearch-latest.zip` below.
2. Extract the archive and quit qBittorrent.
3. Run `install/macos.sh` on macOS, `install/linux.sh` on Linux, or
   `install/windows.ps1` in Windows PowerShell.
4. Relaunch qBittorrent and open the Search tab.

The archive includes the standalone engines, matching icons, support files,
platform installers, and upstream license notices. See documentation/INSTALL.md
for setup and documentation/LICENSE_PROVENANCE.md for the licensing audit.
