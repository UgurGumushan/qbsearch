# Repository commands

This file is generated by `bun run gen -- --write --only cli`. Do not hand-edit.

Use `bun run <command> -- --help` for full flags.

## `bun run setup`

Install pinned Bun/Python checkers and enable the pre-commit hook.

```sh
bun run setup
```

## `bun run check`

Run deterministic checks. --fast is the pre-commit hook subset; --full (default) adds bun test.

```sh
bun run check
bun run check -- --fast
bun run check -- --full
```

## `bun run gen`

Regenerate or audit generated files (catalog docs, preambles, icons, CLI docs).

```sh
bun run gen -- --check
bun run gen -- --write --only catalog
```

## `bun run plugin`

Validate or scaffold standalone plugins.

```sh
bun run plugin -- --validate
bun run plugin -- --new myengine --kind json
```

## `bun run test`

Run deterministic bun tests, or live network tests with --live.

```sh
bun run test
bun run test -- --watch
bun run test -- --live --plugin yts
bun run test -- --live --plugin yts --require-results
bun run test -- --live --record-probes
```

## `bun run release`

Build a release ZIP after validating the catalog.

```sh
bun run release -- 0.1.3
```
